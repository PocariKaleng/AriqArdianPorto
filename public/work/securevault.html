Introduction

SecureVault is a private file archive that runs entirely in the browser. Files are encrypted with AES-256-GCM through the Web Crypto API and kept in a local IndexedDB vault, so there is no account and no server upload.

It also has a digital-signature lab: sign a message with ECDSA P-256 and watch verification fail the moment one character changes.

  • Encrypt a file and download the archive
  • Open an encrypted file with its password
  • Keep archives in a local vault
  • Sign and verify messages with ECDSA P-256
  • Review every action in the audit log
